# 🖋️ MarkTypo - 极简高颜值本地 Markdown 编辑器

> **MarkTypo** 是一款完全免费、轻量、高颜值的 **Typora 风格本地 Markdown 编辑器**。专为个人高效写作、技术博客、学术笔记与日常待办打造。告别传统双栏编辑器的视线割裂，享受原汁原味的**真·所见即所得 (WYSIWYG)** 体验！

---

## ✨ 核心特性亮点

### 1. 🎯 真·所见即所得 (Seamless WYSIWYG)
- **隐式语法排版**：输入 Markdown 语法（如 `# 标题`、`**加粗**`、`*斜体*`、`~~删除线~~`、`==高亮==`、`[x] 待办`）自动就地渲染。
- **光标在位编辑**：无需右侧多余预览窗口，直接在排版后的正文上进行光标选择与编辑。
- **毫秒级双模切换**：按下快捷键 **\`Ctrl + /\`**，即刻在「所见即所得」与「纯文本源码模式」之间无缝切换，数据双向无损同步。

### 2. 📁 本地文件系统工作区 (Workspace & Tabs)
- **打开本地文件夹**：依托现代 Web File System Access API，直接选择本地目录即可载入完整文件树。
- **多标签页 (Multi-Tab)**：支持同时打开多个 `.md` 文档自由切换，具备未保存脏修改提示圆点与防关闭确认。
- **自动保存 (Auto-save)**：支持后台定时自动将修改同步回本地磁盘文件，无需担心断电或意外关闭。
- **内置示例库**：初次使用可一键载入丰富的内置示例知识库（含学术笔记、技术架构图、工作清单）。

### 3. 📑 实时层级大纲导航 (Outline / TOC)
- 实时自动提取文章内所有 `H1 ~ H6` 层级标题。
- 树状层级缩进展示，点击任一节点即可**平滑平移滚动**并伴随高亮提示。
- 无论处于所见即所得还是源码模式，大纲均可双向联动。

### 4. 🔬 块级深度支持
- **可视化交互表格**：支持随时插入表格，提供悬浮工具栏一键增删行、增删列、切换表头行、按 Tab 键自动跳转。
- **LaTeX / KaTeX 数学公式**：支持行内公式（`$E=mc^2$`）与独立块级公式（`$$\int ...$$`），实时高清矢量渲染。
- **Mermaid 矢量图表**：支持流程图 (`flowchart`)、时序图 (`sequenceDiagram`)、状态机 (`stateDiagram`)、甘特图等，支持在图表渲染与源码编辑间一键切换。
- **多语言代码高亮**：基于 Highlight.js，内置深色精致代码容器，支持 50+ 主流语言、行号与一键复制代码。
- **截图与图片直接粘贴**：支持从剪贴板直接 `Ctrl+V` 粘贴图片或将图片文件拖入编辑器，自动转为 Base64 / 嵌入。

### 5. 🎨 沉浸模式与多套主题
- **多套精选主题**：
  - `Github 浅色`：经典 Typora 雅致白底排版。
  - `Night 极夜深色`：舒适护眼暗色模式。
  - `Sepia 羊皮纸`：温润泛黄复古纸张风。
  - `Nord 极光`：北欧冷淡极简风。
- **专注模式 (F11)**：一键隐藏所有侧边栏、标签栏与工具栏，只保留中央纯粹纸张。
- **打字机模式 (Typewriter)**：输入时当前行始终保持在视口垂直居中。

### 6. 📤 多格式专业导出
- **导出独立 HTML**：自包含所有排版样式、KaTeX 公式 CSS 与代码高亮样式，单个 `.html` 文件发给任何人离线双击即可完美阅读。
- **导出 / 打印 PDF**：专门优化 `@media print` 样式，隐藏辅助边框，输出标准精美 A4 排版。
- **保存 / 导出 Markdown**：随时保存回本地 `.md` 文件。

## 📦 软件安装包与启动方式（提供两种桌面模式）

### 模式一：标准 Windows 安装包安装（⭐ 推荐，全新发布）

软件已完全编译打包为标准 Windows `.exe` 安装程序：

1. **桌面安装包**：
   - 编译生成路径：`release/MarkTypo Setup 1.0.0.exe`
2. **安装步骤**：
   - 直接双击 **`MarkTypo Setup 1.0.0.exe`**；
   - 弹出标准安装向导，你可以自定义选择安装磁盘与目录；
   - 安装程序会自动创建**桌面图标**、**开始菜单项**与**系统注册表关联**；
   - 安装完成后即可随时双击启动！

---

### 模式二：绿色免安装便携版 (Portable)

如果你不想进行安装，可以直接使用绿色单目录版：
- 可执行文件路径：`release/win-unpacked/MarkTypo.exe`
- 直接双击 `MarkTypo.exe` 即可瞬间秒开运行，无需安装，随拷随走（支持放入 U 盘在任何 Windows 电脑即开即用）。

---

### 模式三：本地源码开发启动
```bash
# 启动桌面客户端
npm run app

# 或启动 Web 预览模式
npm run dev
```

## ⌨️ 常用快捷键速查

| 快捷键 | 对应操作 | 说明 |
| :--- | :--- | :--- |
| **`Ctrl + /`** | 切换编辑模式 | 所见即所得 (WYSIWYG) ⇋ 源码模式 |
| **`Ctrl + S`** | 保存当前文件 | 自动写回本地磁盘 |
| **`Ctrl + N`** | 新建空白文档 | 打开新的编辑 Tab |
| **`Ctrl + O`** | 打开本地单文件 | 唤起系统文件选择框 |
| **`Ctrl + Shift + O`** | 打开本地文件夹 | 加载工作区目录树 |
| **`Ctrl + 1 ~ 6`** | 设为 1 ~ 6 级标题 | 调整当前段落层级 |
| **`Ctrl + 0`** | 重置为正文段落 | 取消标题格式 |
| **`Ctrl + B`** | 粗体文字 | 加粗选中文本 |
| **`Ctrl + I`** | 斜体文字 | 倾斜选中文本 |
| **`Ctrl + U`** | 下划线 | 添加下划线 |
| **`Ctrl + Shift + X`** | 删除线 | 添加删除线 |
| **`Ctrl + K`** | 插入超链接 | 唤起链接输入浮窗 |
| **`Ctrl + T`** | 插入交互表格 | 生成 3x3 表格 |
| **`F11`** | 沉浸专注模式 | 隐藏一切干扰项 |
| **`Tab`** | 缩进 | 源码模式缩进 2 空格 / 列表分级 |
